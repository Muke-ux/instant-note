# 即时备忘

一个轻量桌面备忘录。核心想法一句话：**在你最容易忘记的时刻，把待办糊到屏幕上。**

29 MB 绿色版，双击就用，不装任何东西，不写注册表，不联网。

## 特点

- **开机全屏提醒** — 登录后自动铺满屏幕，一次看清今天要做什么
- **熄屏回来提醒** — 关显示器再打开时自动弹出
- **定时循环提醒** — 默认 30 分钟一次，可调
- **桌面浮窗** — 常驻右下角，随时看一眼，可直接打勾
- **Alt+L 一键关屏** — 任何时候按一下，立即关闭显示器
- **分类筛选** — 浮窗和全屏都能按类别过滤

## 使用

双击 **`启动.bat`**。

设置开机自启：右键 `设置开机自启(管理员).bat` → 以管理员身份运行。
取消：右键 `取消开机自启.bat` → 以管理员身份运行。

详细说明见 [`说明.md`](说明.md)。

## 技术栈

Python 3.12 + tkinter，只用标准库，零第三方依赖。

几个关键实现：

- **全局热键**用独立进程（`hotkey.py`）跑 `RegisterHotKey`。ctypes 注册的窗口过程回调进入时不持有 Python 线程状态，在 tkinter 进程里会直接把解释器搞崩，所以必须拆出去。
- **熄屏检测**用 `RegisterPowerSettingNotification` + `GUID_CONSOLE_DISPLAY_STATE`。关显示器不触发锁屏事件、也不产生普通程序能感知的消息，这是唯一可靠的信号源。
- **DPI 感知**在创建 Tk 之前调 `SetProcessDpiAwarenessContext(-4)`，150% 缩放下文字依然锐利。

## 目录

```
├─ 启动.bat                  启动程序
├─ 设置开机自启(管理员).bat       注册计划任务
├─ 取消开机自启.bat              删除计划任务
├─ 说明.md                   完整使用说明
├─ app\
│  ├─ main.py                主程序（界面 + 熄屏检测 + 数据）
│  ├─ hotkey.py              Alt+L 守护进程
│  ├─ test_tick.py           熄屏判定自检，跑一遍应输出 ALL-PASS
│  └─ data\state.json        备忘数据（本地生成，不进版本库）
└─ python\                   精简过的 Python 运行时
```

## 数据

`app\data\state.json`，纯文本 JSON，可以直接用记事本打开。

数据跟着文件夹走 —— 整个 `即时备忘-绿色版` 拷到别的机器就能继续用。

`app\data\state.json` 已在 `.gitignore` 中排除，不会提交到仓库。
